## Notes on scope and what remains open

- **Issue #4's recalibration** is deliberately incomplete: the audit and quantification are done, but changing the operational threshold itself was judged out of scope for a single session (it would touch every previously-published number in this project). This is a decision, not an oversight — see `CLASSIFIER_AUDIT.md` section 5 for the full reasoning.
- **Issue #7's "independent verification"** (a structurally different densification approach) was explicitly scoped as future work, not attempted this session — the brief itself only asked for the wording to be corrected and the gap noted, not for a new verification method to be built.
- **Issue #9's "principled alternative"** (deriving effort weights from a real burden-of-treatment instrument) is noted as a direction, not implemented — would require sourcing external survey/instrument data not currently in this repo.
- `.gitignore` was checked, not modified: the existing patterns (`*.pt`, `*.pth`, `data/*`, `__pycache__/`) already correctly exclude the only disposable artifacts found (four model checkpoint files under `experiments_v2/repro_check/models/`, confirmed via `git check-ignore`). No experiments_v2-v6 source, markdown, or result CSV is excluded by any existing pattern.
